# 课间与我们

面向 `https://zhangning521.github.io/` 的 GitHub Pages 工程。默认显示教学工作台，可以切换到“我们的生活”和原来的樱花音乐相册。

## 页面与扩展

- `index.html`：统一入口与页面切换。
- `workbench.html`：迁移自本机教学工作台，保留课表、空闲时段折叠、课程修正、报销路线、默认 150 元、调休申请标记、CSV 导出。首页“今日安排”下方显示待办，可快速新增、勾选完成，与“我的待办”共用记录。
- `together.html` / `together.js` / `together.css`：照片墙、纪念日、回忆手记、一起的小计划、随机相处灵感、Markdown 回忆录、可断网打开的回忆页。
- `album.html`：旧首页原样保留，仅增加返回工作台链接；原照片、音乐、配置与 CSS 路径保留。

增加新页面时，在 `index.html` 的 `pages` 和导航中注册一个相对地址即可。以后可扩展旅行地图、双人小游戏、语音收藏等。

## 手机使用

手机首页优先显示今日安排与待办，底部可直接切换六个教学页面。课表、行程默认按单日时间表显示，可选周内日期，或切换到完整周表左右滑动。报销、加班记录显示为可编辑卡片，路线、金额与申请标记沿用原有记录。输入框与弹窗适配小屏，桌面仍保留完整周课表和表格。

发布时会给页面中的样式、脚本加上构建版本号，首页也会刷新内嵌页面地址，减少手机缓存旧版的情况。


## 本机数据与迁移

公开源码不包含学生课表、报销记录、飞书账号或新增生活照片。飞书日历由 GitHub Actions 读取，只将加密快照发布到 Pages；浏览器解密后保存课表。工作台手动修改保存于当前浏览器的 localStorage，生活记录和照片保存于 IndexedDB。各设备可以读取同一份飞书日历，但手动修改与生活记录仍需导出/导入备份。

1. 双击 `准备工作台迁移.cmd`，或运行 `node tools/prepare-migration.cjs [原工作台文件夹]`。
2. 得到 `private-export/workbench.personal.json`，其中包含原课程识别配置、安排、修改、路线和标记，不包含 CalDAV 密码。
3. 在在线工作台中打开“日历与数据”，选择该文件导入。
4. 旧备份只需迁移一次。启用下面的云端 CalDAV 同步后，网页可以自动更新日历，保留本浏览器的修正、手动补课、路线、报销与调休标记。

个人迁移文件已被 `.gitignore` 排除，**不要强制加入 Git**。清理浏览器、无痕模式、换域名或设备可能使本机数据不可用，请定期导出备份。原相册中的照片此前已在公开站点上；新增生活照片不会自动上传。

## 飞书日历定时更新（一次配置）

1. 打开[仓库 Secrets](https://github.com/zhangning521/zhangning521.github.io/settings/secrets/actions)，新增三个 **Repository secrets**：

   | Name | Value |
   | --- | --- |
   | `FEISHU_CALDAV_USERNAME` | 离线版使用的飞书 CalDAV 用户名 |
   | `FEISHU_CALDAV_PASSWORD` | 同一份 CalDAV 密码；不是飞书登录密码 |
   | `CALENDAR_PASSPHRASE` | 自己设置的独立网页解密口令，至少 16 个字符，建议随机生成并妥善保存 |

2. Pages 的 Source 使用 **GitHub Actions**（由本项目工作流发布）。
3. 在 [Sync Feishu and deploy Pages](https://github.com/zhangning521/zhangning521.github.io/actions/workflows/pages.yml) 点击 **Run workflow**，等到任务成功。
4. 打开在线工作台，点击“同步飞书”，输入第三项网页解密口令。勾选“记住此浏览器”后，今后打开网页会自动读取；网页保持打开时，每 15 分钟检查一次，也可手动点击按钮。

**首次配置完成前，页面只会显示已有本地数据，不会声称飞书已连接。** CalDAV 用户名和密码仅供 GitHub Actions 运行时使用，不会放到源码、页面、快照或浏览器。网页解密口令用于 AES-256-GCM（PBKDF2-SHA256，310000 次）；随机盐和 IV 随加密快照保存。网页不会向服务器发送解密口令。选择记住时口令保存在当前浏览器，备份 JSON 不包含口令。

计划时间为每小时第 7、22、37、52 分钟（UTC），相隔 15 分钟。GitHub 调度和 Pages 发布可能延迟，并非实时推送；“同步飞书”按钮读取最近一次已发布的快照。如需提前更新，可在 Actions 手动运行任务。公共仓库超过 60 天没有活动时，GitHub 可能暂停定时任务，重新启用即可。

同步范围为过去 365 天至未来 220 天。范围内的飞书新增、修改、取消会更新；范围外历史记录、其他导入日历和手动补课保留。相同系列的修正仍按原 UID 关联。任何日历读取失败、不完整批次、解密失败或旧快照回退都会保留上次数据，失败的云端任务不会覆盖线上站点。飞书账户本身的授权范围与离线版一致，业务代码只执行读取操作。

新设备可以用网页解密口令获取日历；原设备的课程分类配置、手动标记仍需导入备份才能保持一致。生活页与新增照片不参与此项云端同步。

## 本地预览与检查

运行 `本地预览.cmd`，打开 `http://127.0.0.1:18720/`。检查命令：`node tools/check.cjs`、`node tools/check-calendar-sync.cjs`、`python -m unittest discover -s tools -p 'test_*.py'`。

重新从本机工作台生成网页时：`python tools/build-workbench.py --source "原页面绝对路径"`。生成器会去除源页面中的样例与私密课程名、飞书连接和 localhost 网络调用。

## 发布与还原

旧首页对应提交 `7793ba590db34c53e23577dc3464a82d33e037d5`。本项目以该提交为基础，仍保留全部相册媒体文件。更新版本由 `.github/workflows/pages.yml` 打包指定公开网页与媒体并部署到 Pages；原始日历、维护脚本和私人迁移文件不进入发布包。`.nojekyll` 用于直接发布静态文件。

若要恢复旧首页，可将 `album.html` 复制回 `index.html`，或恢复旧提交中的 `index.html`；旧站媒体文件保持原路径。

网站和加密日历在线；报销、调休、手动修正和生活数据留在各自浏览器，不会回写飞书，也没有跨设备编辑数据库。
